# Glosario

```yaml glossary_term
term: visitante
definition: La persona que aporta datos para consultar un proyecto a TBO sin crear una cuenta.
```

```yaml glossary_term
term: solicitud
definition: El conjunto de datos de contacto y proyecto que el visitante confirma para evaluación comercial.
```

```yaml glossary_term
term: brief
definition: El resumen revisable de los nueve campos de una solicitud antes de confirmar su envío.
```

```yaml glossary_term
term: captura
definition: La fase en que el visitante incorpora o corrige los datos de su solicitud mediante escritura o voz.
```

```yaml glossary_term
term: revisión
definition: La fase en que el visitante examina el brief con voz cerrada y actualizaciones de IA bloqueadas.
```

```yaml glossary_term
term: envío pendiente
definition: El estado de un intento de entrega que bloquea nuevas confirmaciones hasta resolverlo.
```

```yaml glossary_term
term: sesión de voz
definition: La conexión activa que permite intercambiar audio y propuestas de actualización con el asistente.
```

```yaml glossary_term
term: conflicto manual
definition: La propuesta de voz que intenta sustituir un campo previamente editado por el visitante.
```

```yaml glossary_term
term: destino comercial
definition: El receptor externo configurado para recibir solicitudes y permitir el seguimiento por TBO.
```

```yaml glossary_term
term: credencial efímera
definition: La autorización temporal de un uso para intentar abrir una sesión de voz sin revelar la clave permanente.
```
